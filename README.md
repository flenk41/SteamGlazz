# SteamGlazz — сканер цен CS2

Сайт и консольная программа для трейдеров скинами CS2:

- **Ниже рынка** — лоты, которые сейчас дешевле обычной цены (медиана реальных продаж за 7 дней или цены на других площадках).
- **Стратегия** — укажите бюджет, срок продажи и ограничения, и программа сама выберет самые выгодные связки
  площадок и составит план сделок (что купить, где и почём выставить, сколько на руки, за сколько дней продастся).
  Три цели: деньги → деньги, вывод баланса Steam, пополнение Steam со скидкой. План выгружается в CSV/JSON;
  в консоли: `npm run scan -- --budget 100 --goal cash|steam-out|steam-in --horizon 7`.
- **Арбитраж** — купить на одной площадке, продать на другой; профит и ROI считаются после комиссий.
- **Движение** — топ роста и падения за 24ч / 7д / 30д. Пока своей истории меньше периода, сравниваются медианы
  продаж Skinport (последний период против более длинного) — с проверкой, что текущие лоты двигаются туда же;
  когда история накопится, «Авто» переключается на сравнение цен лотов со снимком N часов назад.
- **Скин** — карточка для решения о сделке: сколько стоит сейчас и где дешевле, за сколько можно продать
  и сколько останется на руках после комиссии, процент профита, ликвидность (продажи в Steam за 24 ч + Skinport).
- **Рубли** — переключатель $ / ₽ в шапке; курс ЦБ РФ (обновляется раз в час) или свой во вкладке «Комиссии».
  Фильтры, графики и выгрузки работают в выбранной валюте.
- **Сравнение** — цены одного предмета на всех площадках, плюс прямые ссылки на Steam, CS.MONEY, CSFloat и BUFF163. Есть избранное.
- **История цен и графики** — на странице сравнения: график по всем площадкам и медиане продаж за 24ч / 7д / 30д / 90д / всё время,
  изменение цены за период, медианы продаж Skinport за 24ч–90д, табличный вид.
- **Выгрузка** — CSV (сразу открывается в русском Excel) и JSON с текущими фильтрами.
- **Сканер** `npm run scan` — то же в терминале, с режимом наблюдения и уведомлениями в Telegram.

## Запуск

Нужен Node.js 22.18+ (TypeScript запускается без сборки).

```bash
npm install
npm start          # http://localhost:3000
```

## Сканер для перепродажи

```bash
npm run scan                                         # один проход, топ-25 + файлы в exports/
npm run scan -- --min-profit 2 --min-roi 8           # фильтры
npm run scan -- --buy lisskins,skinport --sell marketcsgo
npm run scan -- --watch 300                          # каждые 5 минут, сообщает о новых связках
npm run scan -- --help
```

Для уведомлений в Telegram скопируйте `.env.example` в `.env` и заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

## Откуда цены

| Площадка | Источник | Обновление |
|---|---|---|
| Skinport | официальный публичный API `/v1/items` и `/v1/sales/history` | 5 / 15 мин |
| Market.CSGO | `market.csgo.com/api/v2/prices/USD.json` | 3 мин |
| LIS-SKINS | `lis-skins.com/market_export_json/csgo.json` | 5 мин |
| Steam | фоновый обход ~5000 популярных предметов (`STEAM_CRAWL_LIMIT`), живая цена и продажи за 24 ч в карточке | круг ≈ 25 мин |
| CS.MONEY, CSFloat, BUFF163 | открытого массового API нет → ссылки на странице сравнения | — |
| Курс USD→RUB | ЦБ РФ (`cbr-xml-daily.ru`) | 1 ч |

Деньги от продажи в Steam остаются на балансе Steam и не выводятся, поэтому в арбитраже и сканере продажа
в Steam по умолчанию выключена (включается чипом «Steam» в «Продаю на» или `--sell steam`).

Данные кэшируются в `data/cache/`, лимиты площадок соблюдаются (Skinport: не чаще 8 запросов за 5 минут).

## История цен

Бесплатные API не отдают историю, поэтому SteamGlazz собирает её сам в `data/history.db` (встроенный SQLite в Node).
Пока запущен сервер (`npm start`) или сканер (`npm run scan -- --watch …`), каждое обновление цен сохраняется:
не чаще раза в час на предмет и площадку, и только если цена сдвинулась на ≥ 0,5 % (иначе — контрольная точка раз в 6 ч).
Хранятся последние 180 дней. Чем дольше работает сервер, тем длиннее графики.

## Как считается

- **Арбитраж:** `профит = цена продажи × (1 − комиссия продажи) − цена покупки × (1 + доп. расход)`.
  Цена продажи — минимальный лот на площадке продажи минус 1¢; в режиме «Осторожно» — не выше медианы продаж за 7 дней.
- **Ликвидность** — число продаж за 7 дней на Skinport (фильтр «Продаж за 7д»).
- **Подозрительные** — ROI выше 100% или единственный лот на площадке продажи: часто это редкий float/паттерн или ошибка данных.

Комиссии по умолчанию лежат в `server/config.ts` (Skinport 8%, Market.CSGO 5%, LIS-SKINS 10%) и меняются на вкладке «Комиссии».
**Сверьте их с площадками** — от них целиком зависит результат.

## Структура

```
server/   index.ts (HTTP + API), sources.ts (площадки), store.ts (кэш и сводка), analytics.ts (сделки, арбитраж, CSV)
cli/      scan.ts — консольный сканер
public/   index.html, styles.css, app/main.ts (фронтенд на TS)
```

API: `/api/deals`, `/api/arbitrage`, `/api/movers?period=1d|7d|30d&basis=auto|asks|sales`, `/api/history?name=&range=`, `/api/search?q=`, `/api/item?name=`, `/api/export?type=deals|arbitrage&format=csv|json`, `/api/status`, `POST /api/refresh`.
